# Testing Requirements

Production readiness requires, where applicable:

- typecheck passes
- lint passes
- unit tests pass
- integration tests pass
- production build passes
- Playwright storefront journeys pass
- Playwright admin journeys pass
- Firestore security rules tested
- Google Sheet synchronization tested
- mobile layouts verified
- desktop layouts verified
- cart and checkout verified
- order workflow verified
- error states verified
- empty states verified
- loading states verified
- accessibility basics verified

Mobile QA is mandatory for UI work.
